shot-butcher

25 App Store screenshot styles for iPhone, iPad and Mac. Pick one, and every screenshot, device and language in the set keeps it. Each set below is rendered from the prompt above it, so pasting that prompt into Claude Code with the skill installed gives you the same style for your app.

/plugin marketplace add GraphicMeat/shot-butcher
/plugin install shot-butcher@shot-butcher
